# An-Nahl Management System (AMS)
## Design System

---

# 1. Tujuan

Dokumen ini menjadi standar visual resmi An-Nahl Management System (AMS). Seluruh halaman, komponen, dan fitur wajib mengikuti aturan pada dokumen ini agar tampilan aplikasi konsisten.

---

# 2. Identitas Visual

AMS menggunakan konsep desain:

- Modern
- Minimalis
- Profesional
- Academic
- Architecture Inspired

Inspirasi desain:

- GitHub
- Linear
- Notion
- Vercel

---

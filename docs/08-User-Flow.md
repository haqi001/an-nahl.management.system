# An-Nahl Management System (AMS)

# User Flow

Version : 1.0

---

# 1. Tujuan

Dokumen User Flow menjelaskan alur interaksi pengguna dalam menggunakan setiap fitur pada An-Nahl Management System (AMS).

Dokumen ini menjadi acuan dalam proses pembuatan wireframe, desain UI, frontend, backend, dan pengujian sistem.

---

# 2. Role Pengguna

AMS memiliki empat jenis pengguna.

- Public
- Anggota
- Ketua Department
- Super Admin (BPH)

# An-Nahl Management System (AMS)
## UI/UX Guidelines

---

# 1. Tujuan

Dokumen ini menjadi pedoman resmi dalam merancang antarmuka (UI) dan pengalaman pengguna (UX) An-Nahl Management System agar seluruh halaman memiliki tampilan yang konsisten, modern, mudah digunakan, dan mudah dikembangkan pada periode kepengurusan berikutnya.

---

# 2. Filosofi Desain

AMS dibangun berdasarkan lima prinsip utama.

- Modern
- Minimalis
- Profesional
- Transparan
- Mudah digunakan

Setiap fitur harus memiliki tampilan yang sederhana namun informatif.

---

# 3. Target Pengguna

Sistem memiliki empat jenis pengguna.

## Public

Hanya dapat mengakses informasi umum.

- Profil Himpunan
- Timeline
- Sayembara
- Dokumentasi Publik

---

## Anggota

Dapat melihat informasi internal.

- Arsip
- Database Anggota
- Download Asset
- Dashboard

---

## Ketua Department

Memiliki hak mengelola data department masing-masing.

---

## Super Admin (BPH)

Memiliki seluruh hak akses sistem.

---

# 4. Prinsip UI

Setiap halaman harus mengikuti aturan berikut.

- Konsisten
- Responsif
- Mudah dipahami
- Maksimal tiga klik menuju fitur utama
- Tidak menggunakan warna berlebihan
- Mengutamakan whitespace
- Fokus pada keterbacaan

---

# 5. Struktur Landing Page

Landing Page terdiri dari:

1. Navbar
2. Hero Section
3. Statistik Organisasi
4. Tentang Himpunan
5. Timeline Terdekat
6. Sayembara Terbaru
7. Footer

---

# 6. Struktur Dashboard

Dashboard terdiri dari:

- Sidebar
- Header
- Content Area
- Notification
- User Profile

Seluruh halaman dashboard menggunakan layout yang sama.

---

# 7. Komponen Standar

Komponen yang digunakan di seluruh aplikasi:

- Button
- Card
- Input
- Badge
- Modal
- Dialog
- Table
- Calendar
- Search
- Pagination
- Dropdown
- Avatar

---

# 8. Responsive Design

AMS harus berjalan dengan baik pada:

- Mobile
- Tablet
- Laptop
- Desktop

---

# 9. Accessibility

Seluruh halaman harus:

- Mudah dibaca
- Memiliki kontras warna yang baik
- Mendukung navigasi keyboard
- Memiliki ukuran tombol yang nyaman

---

# 10. Pengembangan Selanjutnya

Dokumen ini dapat diperbarui apabila terdapat penambahan fitur baru pada AMS.
